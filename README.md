# SatGraphs
I wanted to do a repository of some Python files I generated for the different satellite signals we have received with our GR (UC3-Base).
The repository contains:
· cascada_wav.py: como argumento usa el .wav, que debe ser una grabacion en baseband de la señal del satelite. También las diferentes opciones que tiene este archivo Python son: 
      - --norm
      - --foco 
      - --ancho
      - --t0 X --ti Y
      - --fft 2^X 
      -o file_name.png
